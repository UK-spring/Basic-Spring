서버란? 요청을 기다렸다가, 요청이 오면 처리해서 결과를 돌려주는 프로그램이에요.

Spring Boot로 서버 실행위 실습의 스위치

Spring Boot 프로젝트를 실행하면 서버가 켜지고 요청을 기다려요. localhost:8080은 ‘내 컴퓨터에서 켠 서버’라는 뜻이에요.

규칙을 코드로 쓰기어노테이션

“이 주소로 오면 이렇게 응답” 같은 규칙을 자바 코드에 @로 시작하는 표시를 붙여서 스프링에게 알려 줘요.

예: @GetMapping("/hello")

요청 처리하기요청 종류마다 다른 코드가 실행되게 나누고, 결과를 응답해요

Spring MVC란? Spring에서 웹 요청을 받고 응답을 만드는 부분이에요. 요청이 들어오면 알맞은 코드로 보내 주고, 그 코드가 돌려준 결과를 응답으로 바꿔 사용자에게 보내 줍니다.
1

MVC 패턴

코드를 Model(데이터), View(보여 주는 화면), Controller(요청 받고 연결) 세 역할로 나눠 쓰는 방법이에요.

👉 두 방식에서 각각 ‘화면 디자인 바꾸기’를 눌러, 고쳐야 할 범위를 비교해 보세요

버튼을 눌러 보세요.
2

DispatcherServlet

모든 요청이 가장 먼저 도착하는 입구예요. 주소를 보고 담당 Controller를 찾아 넘겨 줘요. 스프링이 미리 만들어 둬서 우리가 만들 필요는 없어요.

👉 왼쪽 요청을 하나씩 보내 보세요

➜
🚪 DispatcherServlet요청 기다리는 중
➜

/members 담당MemberController
/comments 담당CommentController
어떤 요청이든 Controller로 바로 가지 않고, 꼭 DispatcherServlet을 먼저 거쳐요.
